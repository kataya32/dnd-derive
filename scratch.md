# Shared Scratchpad

## Goals
- [ ] Learn Rust
- [ ] Learn to write and use a GUI application
- [ ] Custom Class Builder DnD Application

## Application Description
A DnD class builder for creating spinoff classes of other classes (includes subclasses)

### Features
- [ ] Hitpoint Tracker
- [ ] Leveling System
- [ ] Spell Tracker
- [ ] Spell Slot Tracker
- [ ] Long/Short Rest Buttons
